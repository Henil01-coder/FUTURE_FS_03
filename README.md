# FUTURE_FS_03
The goal was to create a digital presence for this cozy café located in Rajkot. The website features a smooth-scrolling navigation, a digital menu showcasing their highlights like Cheese Fondue and Thai Coconut Soup, and an interactive contact section.

🔹 Key Technical Learnings: 
Semantic HTML5 & Responsive CSS: Utilized Flexbox and Media Queries to ensure a seamless experience across desktop and mobile devices.
Interactive UI: Implemented Vanilla JavaScript for smooth internal navigation (scrollIntoView) and dynamic form handling.
Real-World Integration: Integrated a Google Maps embed to help customers find the physical location on Nana Mava Road easily.


🔹 Tech Stack: 
Frontend: HTML5, CSS3, JavaScript
Design: Clean, warm UI focusing on a "café" aesthetic.
